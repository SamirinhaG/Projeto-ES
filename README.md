Sistema de Gerenciamento de Procedimentos Odontológicos da UniCatólica - Odonto_Uni.

Objetivo:
Automatizar e centralizar o atendimento e a distribuição de pacientes no complexo odontológico da UniCatólica, 
reduzindo a dependência de controles manuais e comunicação informal entre alunos e recepção,
além de acompanhar o progresso de metas acadêmicas e garantir a conformidade com a LGPD.


Instituição: UniCatólica — Centro Universitário Católica do Ceará

Arquitetura:
Estilo: Cliente-Servidor (*Client-Server*) desacoplado com backend em Monólito Modular.
Padrões: Clean Architecture e Domain-Driven Design (DDD).

Linguagens e Frameworks Utilizados:
Linguagens: Java (17+), JavaScript (ES6+), HTML5, CSS3 e SQL.
Frameworks Backend: Spring Boot, Spring Security (autenticação JWT e bcrypt) e Spring Data JPA.
Frameworks Frontend: React.js (ou Vue.js) e Tailwind CSS (ou Bootstrap).
Banco de Dados**: PostgreSQL.
